# Riley Pigneguy Portfolio

This is a static portfolio website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` - page structure and portfolio content
- `styles.css` - custom styling and responsive layout
- `script.js` - hover carousel behavior and reveal animations
- `Assets/` - project screenshots used in the portfolio

## How to run

You do not need to install any dependencies.

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Run a local server

From the project folder, run:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://127.0.0.1:4173
```

To stop the server, press `Ctrl + C`.

## How to edit

- Update text content in `index.html`
- Update colours, spacing, and layout in `styles.css`
- Update carousel timing or interactions in `script.js`
- Replace or add screenshots inside `Assets/`

## Notes

- The project cards use local screenshots from the `Assets/` folder
- Hovering over a project card cycles through its images
- There is no build step or framework setup required
